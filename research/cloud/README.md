# 클라우드 보조 실험 (2026-10-23)

노트북의 r5 재실행과 별도로 클라우드에서 수행한 두 실험의 결과. 운영 코드(`analysis/`)는 변경하지 않음.

## 실험 1. 기존(운영) 모형 구분력 (`c2_auc.py`)

첫 판단 시점(2015년 4분기 말)에 정답이 확정된 코호트(2013년 2분기 실행분까지)로 적합하고, 2013년 3분기부터 2016년 3분기 실행 코호트에서 시간외 평가함.

| 변형 | 적합 건수 | 반복 | AUC | logloss | 실제÷예측 |
|---|---:|---:|---:|---:|---:|
| B0 현행 2010~12 핵심 변수 128회 | 86,624 | 128 | 0.681 | 0.366 | 1.21 |
| B1 2010~13Q2 핵심 변수, 조기 종료 튜닝 | 139,998 | 183 | 0.687 | 0.364 | 1.23 |
| B2 B1 + 확장 변수 | 139,998 | 330 | 0.700 | 0.360 | 1.22 |
| B3 B2 + 적대적 검증 가중 | 139,998 | 195 | 0.699 | 0.361 | 1.23 |
| B4 B2 + 시간 가중(반감 4분기) | 139,998 | 214 | 0.701 | 0.360 | 1.22 |
| B5 B2 + 적대적 + 시간 가중 | 139,998 | 213 | 0.700 | 0.361 | 1.23 |
| B6 2012Q3~13Q2 핵심+확장 변수 | 88,218 | 171 | 0.700 | 0.360 | 1.22 |

- 적합 구간 확대와 확장 변수 추가, 조기 종료 튜닝으로 AUC 0.681에서 0.700으로 상승함.
- 적대적 검증 가중과 시간 가중의 효과는 0.001 이내로 유의하지 않음. 적대적 판별 모형 AUC가 1.000인 이유는 확장 변수 결측 여부가 시기를 그대로 드러내기 때문임.
- 구분력 상한은 0.700 부근으로 판단함. 수준(실제÷예측 1.2)은 적합으로 해소되지 않으며 갱신 규칙의 몫임.

### nowcast_book_rec2 방식

1. 최근 확정 24개월 코호트 4분기에서 두 사상을 적합함. 점수 p에서 h개월 상각 여부(h는 6, 9, 12, 18)로의 사상과 p에서 24개월 상각 여부로의 사상.
2. 보유 코호트별로 관측 가능한 최장 h를 택하고, h개월 사상의 합이 그 코호트의 실제 h개월 상각 건수와 같아지도록 p를 로짓 이동함.
3. 이동한 p를 24개월 사상에 넣어 코호트의 24개월 수준을 추정하고, 보유 대출 전체 추정 합에 맞는 절편 하나를 최종 보정값으로 사용함.

- 보유 코호트 자체의 조기 결과를 쓰므로 갱신 즉시 수준이 맞고, 24개월 사상을 최근 구간에서 적합해 수준 변화를 흡수함.
- 2015년 4분기부터 2016년 2분기는 보유 코호트의 관측 개월 수가 짧아 1.13에서 1.24로 남음. 이 구간은 trend4보다 낫고 early12와 비슷함.
- 운영 반영 시 현행 후보 체계(`analysis/candidates.py`)에 보정 후보 하나로 추가하고, 선택 기준(최근 확정 4분기 유사 원점 적합)은 그대로 두는 편이 안전함.
