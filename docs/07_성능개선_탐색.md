## 1. 선행 연구·공개 구현 조사 요약
| 출처 | 설정 | 시간외 AUC |
|---|---|---|
| K-Dense 사례 보고 | LightGBM, 2007~2014 학습, 2015 평가, 실행 시점 변수 74개 | 0.708 (평균 예측 0.132, 실제 0.149) |
| Shoeibi 외 2026 (arXiv 2609.16102) | 2013, 2016 이전 | 0.653~0.659 |
| GitHub Caio-Fis/credit-risk-portfolio | 연 단위 재학습 / 고정 모형 | 0.654 / 0.628 |
| 본 프로젝트 | LightGBM, 2010~2012 학습, 2013~2016 평가 | 0.679 (재학습 시 0.71 내외) |

- 실행 시점 변수만 쓰는 공개 연구의 시간외 AUC는 0.65~0.71. 순위 성능의 추가 여지는 작고 시점 변화에 따른 확률 수준 차이가 주된 문제라는 점이 공통 결론
- **참고** 상환 시점 이전 지표만으로 사전확률 이동을 맞추는 절편 재보정, 최근 가중 재학습, 조기 연체 대리 지표 활용, 단조 제약

## 2. 입력 변수·모형 탐색 (선택은 개발 구간 선택용 데이터, 시간외 결과는 보고용)
| 설정 | 모형 | 선택용 AUC | 선택용 log loss | 시간외 AUC | 시간외 log loss |
|---|---|---|---|---|---|
| 운영 모형 (2010~2012 학습) | LightGBM 기존 입력 | **0.664** | **0.3372** | **0.679** | **0.3638** |
| | LightGBM 추가 입력 | 0.656 | 0.3386 | 0.675 | 0.3653 |
| | LightGBM 추가 입력 + 튜닝 16회 | 0.660 | 0.3378 | 0.675 | 0.3648 |
| | 로지스틱 추가 입력 | 0.668 | 0.3363 | 0.670 | 0.3684 |
| | 평균 앙상블 | 0.665 | 0.3368 | 0.676 | 0.3651 |
| 재학습 (2013~2014 학습) | LightGBM 기존 입력 | 0.705 | 0.3468 | 0.716 | 0.3648 |
| | LightGBM 추가 입력 + 튜닝 | 0.704 | 0.3473 | 0.717 | 0.3643 |
| | 평균 앙상블 (선택용 최선) | 0.706 | 0.3464 | 0.717 | 0.3643 |

- **추가 입력** 상환 부담률, 소득 대비 리볼빙 잔액, 같은 분기, 세부등급 대비 금리 차이, 계좌 비율, 직업명 범주, 미기재, 전액 대출 채널, 거주 주, 우편번호 3자리 상각률(학습 구간 정답으로만 계산)
- **결론** 운영 모형은 기존 입력이 가장 좋음. 재학습에서는 앙상블이 AUC +0.002 수준으로 차이가 작아 파이프라인에 넣지 않음
- 학습 구간(2010~2012)이 5만 건 수준이라 변수를 늘리면 과적합 쪽으로 기우는 것으로 보임
