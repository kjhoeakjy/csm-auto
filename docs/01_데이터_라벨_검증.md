## 2. 정답 정의
- 원천에 상각일 없음. 관측값은 마지막 납부월과 최종 상태뿐
- **기본 정답(STOP24)** 실행 후 24개월 안에 상환이 중단(마지막 납부월)되고 최종 상태가 상각인 대출
- **정답 확정 시점** 실행월 + 24개월 + 상각 기록 지연 5개월 + 보고 지연 1개월 = **실행 후 30개월**
- 지연 5개월의 근거 (스냅샷 시점 관측)
  - **31~120일 연체 21,467건의 마지막 납부 후 경과** 0~4개월 21,449건, 5개월 이상 18건
  - 채무조정 없는 상각 236,039건 중 마지막 납부 후 4개월 이하 1.8%
  - 채무조정 있는 상각 33,281건 중 4개월 이하 8.0%, 합의 상환액이 마지막 납부월에 섞임
- **한계** 상각일 복원이 아니라 정상 경로에 맞춘 근사임

## 6. 누수 방지
- **모형 입력 금지** 최종 상태, 마지막 납부일, 금액, 누적 상환, 회수액, 잔여 원금, 최근 FICO, 최근 신용조회일, 고충, 채무조정 관련 전 항목, 투자자 배정액
- `config.LEAKAGE` 와 입력 후보 목록의 교집합이 비어 있음을 테스트로 고정
- 시점 T에 쓰는 정답은 `실행월 ≤ T - 30개월` 대출. 테스트, 2015-12/2017-03/2018-12 세 시점에서 확정일이 T 이후인 정답이 섞이지 않음
- 실행 시점 변수도 2019 스냅샷 파일에 기록된 값임. 신청 시점 값으로 기록된다는 데이터 사전 설명을 가정함, **"as-of 가정 하의 과거 분기 재현"**으로 표기
