신용평가모형
자동 점검

신용평가모형은 시간이 지나면 예측이 실제와 어긋남. 이 시스템은 3개월마다 모형의 예측 상각률과 실제 상각률을 비교하고 차이가 크면 모형 수정안을 검증해 담당자에게 권고함. Lending Club 공개 대출 자료로 2015~2018년 13개 분기 운영 재현.

1. 점검 시점 선택막대 이동 또는 분기 표시 클릭
2. 판단 결과 확인상태, 권고, 근거 3개
3. 권고안 효과 확인'권고안 적용 결과' 버튼으로 이후 실제 결과와 비교
데이터, 모형, 작동 방식
데이터
Lending Club 공개 대출 226만 건 (2007~2018년 실행). 대출 실행 시점 정보만 사용
모형
LightGBM (의사결정나무 여러 개를 차례로 결합하는 기계학습 모형). 입력은 대출 금액, 기간, 금리, 등급, 소득, 부채 비율, 신용 이력. 출력은 대출 후 2년 내 상각 확률. 2010~2012년 대출 8.7만 건으로 학습, 이후 기간 AUC 0.68 (0.5 무작위, 1 완전 구분)
상각률
대출 실행 후 2년 내 상환 중단 후 손실 처리(상각) 비율. 결과 확정은 대출 후 30개월
작동 방식
  1. 3개월마다 자동 실행, 그 시점까지 확정된 자료만 사용
  2. 신규 대출 구성, 대출 후 1년 중간 실적, 2년 확정 실적의 예측 대비 차이 점검
  3. 상태 판정 (정상, 주의, 조치 필요, 판단 보류)
  4. 조치 필요 시 수정안 11종(예측치 조정 7, 재학습 4)을 1년 전 자료로 만든 뒤 이후 실적으로 비교
  5. 기준 통과안만 담당자 보고, 적용 여부는 담당자 결정
보고서
규칙 기반 문장과 Claude Opus 5.5 초안. 보고서 수치는 계산 결과와 항목별 자동 대조 후 발행
조치 필요주의정상

상태
권고
근거

    대출 실행 시기별 예측 상각률과 실제 상각률

    회색 구간은 선택 시점에 결과가 확정되지 않은 대출. 그림 위에 마우스를 올리면 분기별 수치 표시

    시점별 판단에 해당 시점까지의 정보만 사용. 권고안 적용 결과는 이후 확정된 실제 결과와 비교한 사후 평가. 공개 자료 기반 과거 재현, 실제 금융회사 운영 사례 아님.
